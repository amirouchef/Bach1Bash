Échauffement : le code de retour

Chaque commande, quand elle se termine, laisse un code de retour : 0 veut dire « tout s’est bien passé », tout autre nombre veut dire « problème ». Il est stocké dans $?.

$ ls /etc
$ echo $?
$ ls /dossier_inexistant
$ echo $?

Dans le 2e cas, le message d’erreur s’affiche et le code n’est plus 0. Pour faire taire une commande quand seul son résultat compte :

$ id root &>/dev/null ; echo $?       # 0 : l’utilisateur existe
$ id toto &>/dev/null ; echo $?       # 1 : il n’existe pas

&>/dev/null envoie tout ce que la commande affiche (résultat et erreurs) dans la « poubelle » du système. C’est la suite de ce qu’on a vu avec > et 2> en séance 1.

À vous : trouvez le code de retour de cd /root, de cat /etc/shadow et de grep root /etc/passwd. Qu’en déduisez-vous ?

Le if et les tests

if [ condition ]; then
    echo "la condition est vraie"
else
    echo "la condition est fausse"
fi                         # fi = if à l’envers : il ferme le bloc
Pièges classiques : les espaces après [ et avant ] sont obligatoires ; et on met les variables entre guillemets : "$x".

Exemple, avec ce que tu as appris en séance 1 :

if [ $# -lt 1 ]; then
    echo "Usage : $0 prenom"
    exit 1                  # on quitte le script avec le code 1 (= erreur)
fi
echo "Bonjour $1 !"

Tester les fichiers

Bash sait poser des questions sur les fichiers, et ça rejoint ce que tu as vu sur les droits.

TestVrai si…
-e "$f"le chemin existe
-f "$f"c’est un fichier ordinaire
-d "$f"c’est un dossier
-r / -w / -xtu as le droit de lire / écrire / exécuter
! testle test est faux (négation)

Pour enchaîner plusieurs cas, on utilise elif (« sinon si ») :

if [ ! -e "$1" ]; then
    echo "n’existe pas"
elif [ -d "$1" ]; then
    echo "c’est un dossier"
elif [ -f "$1" ]; then
    echo "c’est un fichier"
fi

Exercice 2 L’inspecteur de fichiers

Écris inspecteur.sh qui reçoit un chemin en argument et :

  • vérifie qu’on a bien donné un argument (sinon usage + exit 1) ;
  • dit si le chemin n’existe pas (et s’arrête avec exit 2), est un fichier ou est un dossier ;
  • indique pour l’utilisateur courant s’il peut le lire, l’écrire et l’exécuter.

Teste avec : /etc/passwd, /etc, /etc/shadow, /bin/ls, /nimportequoi et un script à toi. Compare ls -l avec les réponses du script.

Un indice

Mets le chemin dans une variable : chemin="$1". Chaque droit a son propre if / else. Le test d’existence s’écrit [ ! -e "$chemin" ].

Le videur

Deux tests utiles pour un administrateur :

if [ "$(id -u)" -eq 0 ]; then     # id -u donne l’UID : 0, c’est root
    echo "je suis root"
fi

if id "$1" &>/dev/null; then       # le if teste directement le code de retour
    echo "$1 existe"
fi

Remarque : après if, on peut mettre n’importe quelle commande. Le then s’exécute si son code de retour est 0. Les crochets [ ] ne sont que la commande test écrite autrement.

Un indice pour le bonus

id -nG nom affiche les groupes de l’utilisateur. Envoie-les dans grep -qw sudo avec un pipe : -q n’affiche rien, -w cherche le mot entier. Et le if teste le code de retour de grep.

Le menu avec case

Quand une variable peut prendre plusieurs valeurs, case est plus lisible qu’une chaîne de elif.

case "$reponse" in
    oui|o) echo "d’accord" ;;
    non|n) echo "tant pis" ;;
    *)     echo "je n’ai pas compris" ;;     # * = tout le reste
esac                                          # esac = case à l’envers

Chaque cas se termine par ;; et le *) final rattrape tout ce qui n’a pas été prévu.

Le défi final : devine le nombre

Défi Le jeu du nombre mystère

Bash sait tirer un nombre au hasard avec $RANDOM (entre 0 et 32767), et calculer avec $(( ... )) :

secret=$(( RANDOM % 100 + 1 ))      # un nombre entre 1 et 100

Écris devine.sh :

  • l’ordinateur tire un nombre secret entre 1 et 100 ;
  • le joueur propose un nombre avec read ;
  • le script répond Trop petit, Trop grand ou Bravo, et révèle le nombre secret.

Pour l’instant, une seule tentative : la boucle arrive en séance 3 et le jeu deviendra complet.

Pour les plus rapides : dis Tu brûles ! si l’écart est de 5 ou moins ; refuse une saisie qui n’est pas un nombre ; accueille le joueur par son prénom, passé en argument.

Un indice

Trois cas, donc if / elif / else, avec -eq, -lt et le reste. Pour l’écart : ecart=$(( essai - secret )), et s’il est négatif, change son signe.
