Bienvenue chez BashCorp. Tu viens d’être embauché·e comme administrateur système d’une startup. Ton chef en a assez de refaire les mêmes commandes à la main toute la journée : ta mission est de les automatiser.

C’est quoi un script ?

Un script est un fichier texte qui contient des commandes, lues et exécutées l’une après l’autre par l’interpréteur (ici bash). Tout ce que tu tapes déjà dans le terminal peut être mis dans un script.

Pourquoi s’en servir ? Pour ne pas se répéter, ne pas se tromper, et pouvoir donner son travail à quelqu’un d’autre.

Préparation (2 minutes)

$ mkdir -p ~/scripts
$ cd ~/scripts
$ nano bonjour.sh

Tu peux utiliser nano ou vim, comme tu préfères. Dans nano : Ctrl+O puis Entrée pour enregistrer, Ctrl+X pour quitter.

Mon premier script

Un script minimal a trois ingrédients :

#!/bin/bash
# Ceci est un commentaire : bash l’ignore, les humains le lisent
echo "Bonjour le monde"
ÉlémentRôle
#!/bin/bashLe shebang : première ligne, elle dit quel interpréteur utiliser
# ...Commentaire : explique ce que fait le script
echoAffiche du texte à l’écran

Deux façons de l’exécuter

$ bash bonjour.sh        # on demande à bash de lire le fichier
$ ./bonjour.sh           # on l’exécute directement… à condition d’avoir le droit x

Variables et saisie

Une variable est une boîte avec un nom, dans laquelle on range une valeur.

nom="Alice"                    # on crée la variable (pas d’espace autour du =)
echo "Je m’appelle $nom"       # on l’utilise avec le $
echo "Date : $(date +%F)"      # $(commande) récupère le résultat d’une commande
Piège classique : nom = "Alice" avec des espaces ne marche pas. Bash croit que nom est une commande. Écris toujours nom="Alice".

Demander une saisie avec read

read -p "Ton prénom ? " prenom
echo "Salut $prenom !"

Variables déjà prêtes à l’emploi : $USER, $HOME, $PWD, $HOSTNAME. Tape echo $USER $HOME pour voir.

Exercice 2 Le bot d’accueil

Écris accueil.sh qui :

  • demande le prénom, puis l’âge ;
  • affiche une phrase personnalisée, par exemple Salut Alice, 19 ans ! ;
  • ajoute une 2e ligne qui indique l’utilisateur Linux connecté et le nom de la machine (avec $(whoami) et $(hostname)).

Bonus : affiche aussi la date du jour dans le format JJ/MM/AAAA (regarde man date, section FORMAT).

Un indice

Une variable par réponse : read -p "..." prenom, puis read -p "..." age. Les guillemets doubles laissent bash remplacer les $variables.

Les arguments

Au lieu de poser une question, on peut donner l’information au lancement du script, comme pour ls -l /etc.

VariableContenuAvec l’exemple

Redirections et pipes

Par défaut, une commande affiche son résultat à l’écran. On peut le rediriger ou l’enchaîner avec une autre commande.

SymboleEffetExemple
>Écrit dans un fichier (écrase)who > connectes.txt
>>Ajoute à la fin du fichierdate >> connectes.txt
2>Redirige les messages d’erreurls /nimportequoi 2> erreurs.txt
|Envoie la sortie d’une commande à la suivantels /etc | wc -l
Attention : un seul > écrase le fichier sans prévenir. Pour garder l’existant, utilise >>.

Exercice 4 Tuyauterie

Directement dans le terminal, sans script :

  1. Combien de fichiers et dossiers y a-t-il dans /etc ?
  2. Enregistre la liste des utilisateurs connectés dans connectes.txt, puis ajoute la date à la suite. Affiche le fichier.
  3. Lance ls /dossier_inexistant en envoyant l’erreur dans erreurs.txt. Que contient le fichier ? Que voit-on à l’écran ?
  4. Affiche les 5 premiers noms de comptes du système, triés par ordre alphabétique (fichier /etc/passwd, commandes cut, sort, head).
Un indice sur le point 4

Dans /etc/passwd, les champs sont séparés par : et le nom du compte est le 1er champ. cut -d: -f1 sait l’extraire.

Le défi final : l’outil n°1

Défi La fiche d’identité de la machine

Ton chef veut un script qui produit, en une commande, une fiche à jour sur la machine. Écris fiche_machine.sh qui affiche et enregistre dans un fichier fiche_NOMDELAMACHINE.txt :

  • un titre et la date et l’heure ;
  • l’utilisateur courant et le nom de la machine ;
  • la version de Debian (fichier /etc/debian_version) ;
  • depuis combien de temps la machine tourne (uptime -p) ;
  • l’espace disque de la racine (df -h /) ;
  • le nombre de comptes présents dans /etc/passwd.

Contraintes : shebang, commentaires, au moins une variable, exécutable avec ./fiche_machine.sh.

Pour les plus rapides : n’affiche à l’écran que le message Fiche enregistrée dans … ; ajoute le nombre de fichiers de ton dossier personnel ; ajoute les 3 dernières connexions (last -n 3).

Un indice

Stocke le nom du fichier dans une variable : FICHE="fiche_$(hostname).txt". Commence par > pour créer le fichier vide, puis >> pour tout le reste.
